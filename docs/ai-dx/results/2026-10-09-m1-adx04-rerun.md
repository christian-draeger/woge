ADX-04 now meets its observable outcomes on both Spring hosts:

- the shell arrives before region work starts, and patch-stream headers arrive while both regions are
  still gated (the #175 fix);
- tests release the regions in both orders with `CompletableDeferred` gates and no sleeps;
- a real Chromium test with JavaScript on loads `/assets/woge/index.js` from the published asset jar
  (the #174 fix) and shows both final regions with no placeholder left;
- with JavaScript off, a normal "Load complete project" link renders every region on the server;
- closing the client response (WebFlux) and the async timeout (MVC) cancel outstanding region work.

Ktor was not exercised. The Spring Boot scaffold publishes only the Spring adapters, so the required
hosts for this consumer are WebFlux and MVC. Ktor parity stays covered by the framework adapter TCK.

The four corrections were: moving functions out of a DSL block (editing mistake), comparing the
normalized media-type header instead of a raw `startsWith`, adding the missing MVC
`pathVariable` import, and generating a fresh page epoch per navigation.
